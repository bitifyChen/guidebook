# 前台動態：連續、分層、柔和收尾

狀態：2026-10-02 規劃規範。搭配 [主視覺方向](frontend-visual-direction.md) 使用；下列數值是原型起點，尚未經本產品實機驗證。

## 參考的範圍

使用者指定只觀察 [原始影片](https://cdn.dribbble.com/userupload/42783402/file/original-527c50dfd640b58b1f9968b64c3c343a.mp4) 的動畫，不沿用其欄位、內容架構或配色。[Pinterest 來源](https://www.pinterest.com/pin/588212401327923273/) 供追溯。

影片約 13.23 秒。以下是畫面觀察，不能由畫面判定其實作套件、精確 easing 或 spring 參數：

| 約略片段 | 觀察 | 在 Guidebook 的轉譯 |
| --- | --- | --- |
| 1～3.5 秒 | 照片卡片左右切換，鄰卡保留，中央焦點清楚 | 相簿或相關景點可採有邊界的橫向切換，不自動輪播 |
| 4.5～5.5 秒 | 選取照片擴展並重新構圖，舊介面淡出，新內容分層進入 | 卡片到詳情保持同圖連續感，文字獨立進出 |
| 7.5～9 秒 | 小型相簿橫向移動 | 縮圖選擇與主圖狀態同步 |
| 9.5～10.75 秒 | 白色資訊 sheet 上升，背景照片同步調整，資訊依序呈現並收穩 | 詳情資訊層與照片協調移動，避免多區同時搶焦點 |

影片未展示返回來源卡片；返回連續性是本產品的延伸提案。

## 動態原則

1. **連續**：使用者看得懂內容從哪裡來、回到哪裡。圖片延續景點身份，日期與捲動位置保持穩定。
2. **分層**：每次轉場只有一個主角。先建立圖片或容器位置，再讓少量內容群組出現，文字不隨圖片拉伸。
3. **柔和收尾**：主要位移先發生，再減速到靜止；不用誇張回彈或長時間漂浮。日常操作仍要快速。

「大量舒服的過渡」指重要狀態都有一致回饋，不是每個元素永遠在動。禁止自動輪播、捲動劫持、裝飾性無限彈跳及逐字、逐列長隊列進場。

## 建議動態 token

| 用途 | 起始時間 | 建議行為 |
| --- | --- | --- |
| 按壓／選取回饋 | 120～180ms | 顏色、透明度或極小 scale，不引起排版位移 |
| 日期／內容切換 | 200～280ms | 短淡入淡出；需要方向時只作小幅位移 |
| Drawer／sheet | 220～300ms | 進入減速、退出略快，背景遮罩同步 |
| 卡片照片展開 | 350～450ms | 容器與圖片裁切協調，保持主體，不縮放文字 |
| 照片切換 | 160～240ms | 新圖可用後淡換，容器尺寸不跳動 |

位移可從 `cubic-bezier(0.22, 1, 0.36, 1)` 的減速曲線試起；淡化可採 ease-out。群組錯開約 30～50ms、最多三組，盡量在同一個總轉場時間內完成。這些都是提案值，不是影片量測結果；依真機手感調整，共用 token 避免各頁任意設定。

## 互動契約

### 卡片 → 詳情 → 返回

- 以所點卡片的圖像作為來源，詳情可立即取得必要資訊；不等待大型照片下載才導航。
- 同圖準備完成才進行連續圖片轉場。來源不在畫面、圖片失敗、直接進入網址或能力不支援時，使用短淡化或立即呈現。
- 返回保留原日期與捲動位置；來源仍存在時可逆向回到來源。來源被移除或篩選掉時正常返回，不強制捲動尋找卡片。
- 過渡層不接收點擊，不形成重複的可聚焦內容；完成或中斷都必須清理。

### 日期與頁面切換

- 選取狀態立即回應；資料尚未就緒時呈現真實載入狀態，不能將上一天資料標示為新日期。
- 快速連點時以最後一次意圖為準，取消過期轉場與資料呈現，不累積播放隊列。
- 固定 navbar 保持穩定；不要對整個 app shell 作 transform，造成 fixed、safe-area 或地圖座標異常。

### Sheet 與確認視窗

- 沿用既有 Dialog／Drawer 的焦點管理、關閉方式與返回行為，動畫只增強呈現。
- 模態開啟後焦點進入、背景不可誤觸；關閉後焦點回到觸發點。動態不能延遲取消或攔截提交。
- 表單保留輸入與錯誤；不因切換動畫重新掛載而丟失內容。鍵盤出現時主要操作仍可到達。
- 圖片隨 sheet 調整只用於相關景點詳情，不套用到每個表單或確認操作。

### 相簿與捲動

- 主圖切換與選中縮圖一致；新圖未解碼時保留原圖，失敗時仍可重試或選別張。
- 橫向手勢不得綁架垂直頁面捲動；提供可點擊替代方式與清楚的目前項目。
- 不加入持續視差或每次捲動重播。地圖本體不為視覺效果反覆掛載或整體縮放。

## 中斷、無障礙與效能

任何動畫都必須能被返回、關閉、重新選取或路由變更中斷；狀態以使用者最新操作為準。卸載時清理動畫、量測與暫存節點，避免透明遮罩殘留而無法點擊。

`prefers-reduced-motion: reduce` 下移除空間縮放、視差、位移及 stagger，直接切換或採不超過 100ms 的短淡化。相同資訊、焦點與操作仍須完整，不依賴 animationend 才解除鎖定。

優先採 Vue／CSS 與既有能力；共享圖片轉場需另行檢查瀏覽器與 PWA 相容性，必須有普通轉場 fallback。本階段不指定或安裝新動畫套件。

優先動畫化 transform／opacity，避免逐幀改動影響排版的尺寸、大片 blur 或 SVG displacement。必要量測集中在開始與結束，避免每幀重複讀寫 layout。圖片預留尺寸與解碼策略依主視覺規範；不得以預載所有大圖換取轉場順滑。

## 驗收情境

- 正常進入詳情與返回：主體位置合理、文字不變形、日期與捲動上下文保留。
- 連點不同卡片、快速換日、轉場中返回或關閉：最終畫面符合最後操作，沒有殘留遮罩或雙重點擊。
- 圖片慢載、失敗、離線、直接進入詳情：功能可立即使用，沒有空白停滯或佈局跳動。
- reduced motion、鍵盤操作、螢幕閱讀器與文字放大：內容可理解，焦點不遺失，不重複宣告轉場副本。
- 手機 Safari、Android Chrome 與安裝版 PWA：檢查真實觸控、系統返回、safe-area 及鍵盤；未測環境需如實記錄。
- 在代表性手機觀察連續操作並檢查效能紀錄，目標接近螢幕正常更新率、無可感知卡頓；若效果造成掉幀或操作延遲，縮減效果後再驗收。

每次交付記錄實際裝置、操作與失敗情境，不能只用桌機錄影判定動態完成。
